# 数据字典

## 1. 学生表 (Student)

| 字段名 | 类型 | 说明 | 主键/外键 |
|-------|------|------|----------|
| 学号 | VARCHAR(20) | 学生唯一标识 | 主键 |
| 姓名 | VARCHAR(50) | 学生姓名 | - |
| 性别 | VARCHAR(10) | 学生性别 | - |
| 出生日期 | DATE | 学生出生日期 | - |
| 班级 | VARCHAR(50) | 学生所在班级 | - |
| 专业 | VARCHAR(100) | 学生所学专业 | - |

## 2. 课程表 (Course)

| 字段名 | 类型 | 说明 | 主键/外键 |
|-------|------|------|----------|
| 课程号 | VARCHAR(20) | 课程唯一标识 | 主键 |
| 课程名 | VARCHAR(100) | 课程名称 | - |
| 学分 | INT | 课程学分 | - |
| 开课学期 | VARCHAR(20) | 课程开设学期 | - |

## 3. 成绩表 (Score)

| 字段名 | 类型 | 说明 | 主键/外键 |
|-------|------|------|----------|
| 学号 | VARCHAR(20) | 学生学号 | 主键，外键(参考学生表) |
| 课程号 | VARCHAR(20) | 课程号 | 主键，外键(参考课程表) |
| 分数 | DECIMAL(5,2) | 学生考试分数 | - |
| 考试日期 | DATE | 考试日期 | - |
